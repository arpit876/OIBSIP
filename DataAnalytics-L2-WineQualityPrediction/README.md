# Task 2 (Level 2) - Wine Quality Prediction

## Objective
Trained and compared multiple classification models to predict wine quality based on physicochemical properties.

## Tech Stack
Python, Pandas, NumPy, Scikit-learn (Random Forest, SGD, SVC), Seaborn

## Key Steps
- EDA and class imbalance discussion
- Quality score binning (Low/Medium/High)
- Training 3 classifiers: Random Forest, SGD, SVC
- Model evaluation with confusion matrices
- Feature importance analysis

- `Task4_Wine_Quality_Prediction.ipynb` - Main notebook
- `winequality_dataset.csv` - Dataset used
