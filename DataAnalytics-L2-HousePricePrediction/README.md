# Task 1 (Level 2) - Predicting House Prices with Linear Regression

## Objective
Built and evaluated a Linear Regression model to predict house prices based on features like number of rooms, crime rate, and pollution levels.

## Tech Stack
Python, Pandas, Scikit-learn, Matplotlib, Seaborn

## Key Steps
- EDA and correlation analysis
- One-Hot Encoding of categorical feature
- Train/test split and model training
- Evaluation using MSE, RMSE, R² score
- Residual plot and coefficient analysis
- Comparison with Ridge and Lasso regression

## Files
- `Task3_House_Price_Prediction.ipynb` - Main notebook
- `housing_dataset.csv` - Dataset used
